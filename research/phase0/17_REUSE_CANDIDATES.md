# Reuse Candidates

## Scope and labels

No source is copied in Phase 0. These labels describe what a later authorized phase may consider after path-level provenance, dependency/SBOM and test review:

- **REUSE:** narrow code/schema/test artifact is plausibly reusable under its permissive license.
- **ADAPT:** permissively licensed implementation is a useful seed but needs Android/Kinetic API and behavior changes.
- **PORT_SEMANTICS:** preserve contracts/invariants and re-express them natively rather than translating line by line.
- **CLEAN_ROOM:** independently implement behavior because license/provenance or safety makes source adaptation inappropriate.
- **REFERENCE_ONLY:** keep as research/test inspiration; not a product component.
- **REJECT:** do not include in Kinetic Core.

Every candidate remains conditional. A repository license does not license model weights, service APIs, fonts/media, opaque binaries, remotely installed packages or all transitive dependencies.

Path convention for the tables: OpenClaw `.../` expands from `Eco_reference/openclaw/apps/android/app/src/main/java/ai/openclaw/app/`; OpenDroid `.../` expands from `Eco_reference/opendroid/app/src/main/java/com/opendroid/ai/`; AndyClaw `AndyClaw/.../` and `app/.../` expand from the library and application Java roots documented in `04_ANDYCLAW_ANALYSIS.md`. Within an **Exact evidence** cell, an unprefixed sibling filename inherits the preceding path's directory.

## Components to reject from Kinetic Core

| Rejected component | Evidence | Reason |
|---|---|---|
| Node/Python/shell compatibility substrate | OpenClaw Node host/plugin/skills; Hermes terminal/scripts; AnyClaw `cli.go`/`script.go` | Play/dynamic-code/security/dependency burden; not needed for a native Android kernel |
| Embedded arbitrary plugin loader or downloaded DEX/JAR/SO | OpenClaw/Hermes plugin expectations; Android policy matrix | Expands trusted computing base and conflicts with Core's declarative/signed capability model |
| General LLM-controlled AccessibilityService in Play Core | OpenDroid accessibility modules; OpenClaw third-party flavor | Current audit assumption and Play policy evidence exclude it as a Core dependency |
| `MANAGE_EXTERNAL_STORAGE` file agent | OpenDroid advanced storage actions/manifest | SAF/app-private/MediaStore alternatives; excessive data authority and Play risk |
| Safety that can be disabled globally/YOLO | AndyClaw `SafetyLayer.kt`, OpenDroid `AutoApprovalPolicy.kt` | A preference must not erase hard policy, secrets, publisher identity or irreversible confirmation floors |
| AnyClaw shell/script/browser-eval adapters | `internal/adapter/cli.go`, `script.go`, `pipeline.go`; Chrome extension | Command injection, arbitrary code, SSRF/browser/cookie authority and no tests |
| AndyClaw supplied `llamatik.aar`, `tinfoil-bridge.aar`, vendored Whisper/model assets | Paths and artifact ledger in `04_ANDYCLAW_ANALYSIS.md` | GPL/unknown provenance, opaque binaries, unresolved model/source notices |
| Hermes restrictive productivity skills | `skills/productivity/{docx,pdf,powerpoint,xlsx}/LICENSE.txt` | Terms prohibit ordinary extraction/reproduction/derivative use; root MIT does not apply as assumed |
| MobileRun source copying before commit recovery | entire `Eco_reference/mobilerun-main` archive | Exact source revision unknown and key behavior external; semantic research only for now |
| AirLLM Python implementation on Android | `air_llm/airllm/airllm_base.py` and dependencies | Solves different hardware/runtime problem; no Android backend or acceptable dependency envelope established |

## Suggested reuse order for a later authorized phase

1. Start from **contracts and tests**, not copied frameworks: capability/effect lifecycle, provider stream/error contract, durable outbox/recovery and Android permission behavior.
2. Evaluate narrow OpenClaw Android MIT components and OpenDroid Apache-2.0 components class by class against the future Kinetic interfaces.
3. Translate Hermes/OpenClaw control-plane invariants into Kotlin only after the durable state and security contracts are fixed.
4. Recover MobileRun provenance and use its UI/trajectory tests as evaluation assets; independently implement the Android adapter.
5. Treat AndyClaw as clean-room behavioral evidence and a negative-test source unless Kinetic deliberately adopts GPL-compatible licensing.
6. Add AnyClaw-style declarative/OpenAPI import only after Skill IR and network/secret policy exist.
7. Revisit AirLLM only if measured local-model storage/residency bottlenecks justify it.

## Reuse acceptance checklist

Before any candidate enters a future implementation phase:

- exact source repository, audited commit, upstream origin, path and nearest license are recorded;
- file/subtree headers, notices, generated assets, dependencies, model/service terms and transitive native libraries are reviewed;
- the candidate maps to a frozen Kinetic interface rather than defining it by accident;
- original tests/test vectors and new Kinetic security/lifecycle tests are identified;
- Android lifecycle, cancellation, permission denial and process-death behavior are explicit;
- data sensitivity, network destination, audit and backup behavior are reviewed;
- Play and Advanced artifacts are tested for compile-time separation;
- substantial modifications retain attribution and, for Apache-2.0, required notices/modified-file markings;
- no GPL, restrictive, unknown-provenance or dynamically executable material enters a non-GPL Play Core build.

The practical reuse pool is therefore real but narrow: **OpenClaw Android + OpenClaw portable contracts + OpenDroid Android infrastructure**, supported by semantic ports from Hermes and evaluation/contracts from MobileRun. Everything else is conditional, clean-room or research-only.
